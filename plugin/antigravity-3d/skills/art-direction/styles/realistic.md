# Realistic

Physically plausible materials at real-world scale; the geometry carries the construction, the maps carry the
surface.

## What the pipeline applies

| Value | Setting | Source |
|---|---|---|
| Triangle budget, prop | engine budget | upstream asks for the upper range; a style never raises the engine budget |
| Triangle budget, kit piece | engine budget | as above |
| Shading crease angle | project default | no number upstream |
| Texture size, prop | 2048 px | upstream realistic skill: game textures, typical maximum |
| Texture size, kit trim sheet | 4096 px | upstream polycount budgets: shared trim sheets (upper end) |
| Texture filtering | engine default | |
| Albedo palette | no limit | |

Texture sizes are capped by the target engine's limit.

## Building it

- Check scale against known dimensions (a door, a hand, a step) before adding detail.
- Model what changes the silhouette or casts a visible shadow; leave scratches, grain and small dents to the maps.
- Materials: metallic is 0 or 1 except at a painted transition; dielectric albedo never pure black or white. The
  pipeline's albedo range normalisation already enforces the second rule.
- LODs are generated by the pipeline; nothing to do here.

## Not applied (needs a pipeline feature)

High-to-low baking from a dense source mesh, scan clean-up, and per-material reference values (the pipeline derives
roughness and metallic from the generated albedo).
