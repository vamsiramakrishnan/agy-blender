# Straitjacket 3D Scroll Storyboard

## Design rules (from `straitjacket/docs/VISUAL-DESIGN.md`)
- **Allowed:** Addressable Evidence visual language — dark instrument bench (`#0D0F12` bg, `#15181D` surface, `#1C2026` surface2, `#ECEAE3` ink, `#8D939A` muted, `#272C33` grid), semantic colour only (Blue `#6F96FF` bounded/addressed/controlled, Amber `#F0B429` identity/receipt/decision point, Red `#FF7768` resident flood/loss/unsupported boundary, Green `#63D3A4` verified outcome, Neutral `#242931` machined structure), square corners, 1px rules, 64px grid rhythm, uppercase display claims, sentence-case body, JetBrains Mono for byte-shaped evidence, every number sourced via `data-src`.
- **Forbidden:** No gradients, no glow or bloom, no glass/blur effects, no decorative colour, no atmospheric particles, no invented receipts/handles/line numbers, never rely on colour alone.

## Props (3 open mechanical instruments, built with `antigravity-3d`)

1. **`digest_press`** (`at: [0, 0, 0]`, `turn: 0`, size `[1.8, 1.45, 1.3]` m):
   Open machined-steel log containment press (`#242931`) with heavy intake feed rollers on +X, open vertical gantry columns holding a suspended pressing platen over an exposed sorting bed (clear through-channel so slabs visibly pass underneath), amber (`#F0B429`) receipt-stamper carriage on an overhead linear rail, and a blue (`#6F96FF`) bounded output chute on -X.
2. **`anchor_rack`** (`at: [-3.4, 0, -0.5]`, `turn: 0.25`, size `[1.5, 1.55, 1.0]` m):
   Open vertical archive and content-anchor verification rack (`#242931`) with one lower specimen drawer pulled open on telescopic rails exposing stored artifact cartridges, an open upper slotted bay for shifting code-span bars, a sliding amber (`#F0B429`) optical caliper arm on a vertical lead screw, a green (`#63D3A4`) verification lock bar, and a red (`#FF7768`) refusal stop indicator at the top rail.
3. **`host_manifold`** (`at: [-1.7, 0, -3.4]`, `turn: 0.08`, size `[2.5, 1.15, 1.15]` m):
   Open seven-lane mechanical gate manifold (`#242931`) with seven parallel open troughs/channels separated by machined dividers, two overhead gate bridges spanning all seven lanes — front Birth Gate (`PreToolUse`) and rear Output Gate (`PostToolUse`) — with distinct semantic baffles per lane (blue `#6F96FF` active bounded gates, amber `#F0B429` birth-rewrite gate on lane 3, red `#FF7768` open/unsupported output boundary on lane 3).

## Instanced Layers & Shaders
- **`floor`**: `CustomShaderMaterial` (`MeshStandardMaterial`) with `GROUND_LIGHT` / `GROUND_ENVIRONMENT`, `fwidth`-antialiased metric bench grid and active station evidence trace rail connecting `digest_press` → `anchor_rack` → `host_manifold`.
- **`flood`**: One `InstancedMesh` of 6,053 slabs (50 tokens/slab = 302,628 tokens) collapsing cleanly through `digest_press` into 11 kept slabs (10 blue digest slabs + 1 amber needle slab = 531 tokens, 570×).
- **`needle`**: Digest specimen rail + amber `L14238` quiet-needle shuttle travelling from `digest_press` exit into `anchor_rack`'s open drawer.
- **`anchors`**: `InstancedMesh` (`RoundedBoxGeometry`, 32 code-span bars) shifting inside `anchor_rack` with a moving amber caliper indicator locking onto the relocated green span and refusing a rewritten red span.
- **`lanes`**: `InstancedMesh` (7 parallel lanes × 6 evidence packets = 42 packets) flowing through `host_manifold`'s birth and output gates.
