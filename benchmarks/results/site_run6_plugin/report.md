### What could not be done
- **Verified native Decisions API approval on the 3D packages**: This environment's key has no access to the native Decisions API, so all three `antigravity-3d` packages were delivered as `UNVERIFIED` preview exports (`verified: false`, judged by the uncalibrated fallback judge rather than a native Decisions API verdict).
- **Godot 4 native import check**: Because the three props are delivered directly to the three.js browser site, they were exported with target engine `web_three` (which runs Blender validation and headless three.js import + parity checks) rather than as Godot 4 packages, so no headless Godot import pass was run on them.
- **Network-dependent packages or KTX2/gltfpack binaries**: Offline sandbox had no internet access and no native `gltfpack`/`ktx` binaries; `install_into_project` kept WebP-textured GLBs (`--compress auto`) because the JS-only KTX2 transcoder (`585 kB`) would have increased total download size.
