02 / THE CONTEXT FLOOD

04 / LOCAL ARTIFACT STORE

PULL ONLY THE LINES THAT DECIDE

Full streams reside locally up to 64 MiB per stream. Search by handle and fetch the exact slice you need—leaving earlier prompt turns untouched so prefix caches stay valid.

ctx search run:8d8335db6848#stdout "MissingTenantError"
ctx get run:8d8335db6848#stdout --lines 1280:1300
