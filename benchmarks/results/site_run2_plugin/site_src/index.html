04 / LOCAL ARTIFACT VAULT

FETCH ONLY WHAT CHANGES THE NEXT STEP

Full streams remain in the local store. When a model needs a traceback or symbol definition, it queries the handle and appends a narrow line range at the end—leaving earlier prompt bytes intact for prefix cache reuse.

ctx search run:8d8335db6848#stdout "MissingTenantError"
ctx get run:8d8335db6848#stdout --lines 1280:1300
ctx search repo: sym:parse_ref
ctx def repo:src/ctx/refs.py:parse_ref
ctx refs parse_ref --path src/ctx
