# Straitjacket Scroll-3D Website Storyboard

## Visual Design Rules (from `straitjacket/docs/VISUAL-DESIGN.md` & `scripts/gen_addressable_evidence_visuals.py`)

- **Allowed**: Semantic colour ONLY (`#0D0F12` dark bg, `#15181D` surface/ground, `#1C2026` surface2, `#ECEAE3` ink, `#8D939A` muted, `#272C33` 1px rules/grid; Blue `#6F96FF` = bounded/addressed/controlled; Amber `#F0B429` = identity/receipt/decision point/quiet needle; Red `#FF7768` = resident flood/loss/unsupported boundary; Green `#63D3A4` = verified outcome; Neutral = storage/structure/unselected context). Square corners (`border-radius: 0`), 1px architectural rules, instrument-panel layout, short uppercase display claims, large tabular figures, sentence-case prose, JetBrains Mono for byte-shaped evidence, receipts naming checked-in source files.
- **Forbidden**: NO gradients, NO glow (no BloomEffect), NO glass/frosted-glass effects, NO decorative/atmospheric colour, NO invented receipts/handles/line numbers (illustrative graphics must say they are illustrative).

## World Concept: The Evidence Bench

One continuous dark calibrated architectural bench (`x = 0` to `x = 6.0` m) showing the evidence path: **command → capture → digest → address → retrieval → anchor verification → multi-host routing**. Three bespoke industrial-instrument 3D props stand along a ruled tracking rail, joined by scroll-driven `InstancedMesh` token/line slabs (`CustomShaderMaterial` + matching `customDepthMaterial`) and local-font `troika-three-text` instrument markings. Every visual value is a pure deterministic function of story time `T`.
