03 LOCAL ARTIFACT VAULT · run: HANDLE

CAPTURED ONCE. PULLED BY ADDRESS.

Full stdout and stderr stay in Straitjacket's local store (64 MiB default per stream) instead of riding on every turn. When the agent needs a traceback, ctx search and ctx get pull only the bounded slice—leaving the earlier prompt prefix intact for cache reuse.

ctx search run:8d8335db6848#stdout "MissingTenantError"
ctx get run:8d8335db6848#stdout --lines 1280:1300
STREAM LIMIT 64 MiB local capture store
CANARY CACHE HIT 96.5% → 97.5% 3-task canary (cost $0.67 → $0.92)

05 SEVEN-LANE HOST MANIFOLD · ACP + GATES

SEVEN HARNESSES. TWO ENFORCEMENT GATES.

Straitjacket wraps your existing coding agent at the birth gate (PreToolUse) or output gate (PostToolUse). Claude Code and Codex bound oversized results after execution; Antigravity rewrites supported calls before execution because its output hook accepts no replacement. Through ctx orchestrate and ACP, workers pass checkpoints and handles across lanes.

  • Claude Codeoutput gate
  • Codex CLIoutput gate
  • Antigravitybirth rewrite
  • Hermesbirth + output
  • Oh My Pibirth + output
  • OpenCodebirth + output
  • DeepSeek Harnessgate + replace
