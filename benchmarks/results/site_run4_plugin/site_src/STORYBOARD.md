# Straitjacket — Scroll-Driven 3D Website Storyboard

## Visual Design Rules (from `straitjacket/docs/VISUAL-DESIGN.md` & `assets/icon/README.md`)

- **Allowed:** Dark instrument-panel ground (`#0D0F12`), surfaces (`#15181D`, `#1C2026`), warm-white ink (`#ECEAE3`), muted grey (`#8D939A`), 1px grid rules (`#272C33`), square corners (`border-radius: 0`), tabular display figures (Space Grotesk), byte-shaped evidence in JetBrains Mono. Strictly semantic colours: Blue `#6F96FF` (bounded, addressed, controlled), Amber `#F0B429` (identity, receipt, decision point, straps), Red `#FF7768` (resident flood, loss, unsupported boundary), Green `#63D3A4` (verified outcome), Neutral `#8D939A` (storage, structure). Every metric backed by a checked-in receipt via `data-src`.
- **Forbidden:** Gradients, glow/bloom, glassmorphism, decorative/atmospheric colour, rounded marketing cards, particle fields, or invented receipts/handles/line numbers.

## The Followed Thing

A **20,001-line integration log (`302,628` tokens)** hiding one quiet needle at line **14,238** — tracked down one continuous machined instrument bench from raw command flood, through Straitjacket's open Containment Press into a **531-token** digest (`570×` reduction, needle preserved, retrieval handle stamped), into the open-drawer Evidence Vault (stored locally on disk; only the requested lines retrieved on demand), across the Anchor Caliper (relocating `repo:` source ranges after edits with `0` wrong answers), and through the Seven-Lane Host Manifold (birth & output gates across all 7 coding harnesses).
